# Custom Title Editor for YOURLS

A simple and lightweight YOURLS plugin that allows you to easily change your YOURLS admin page title directly from the web interface.

YOURLSの管理画面やブラウザタブに表示されるページタイトルを、設定画面からいつでも自由に変更できる軽量プラグインです。

## Features

- **No Code Required:** Change your site title without editing `config.php` or core system files.
- **Instant Reflect:** The title updates immediately across your entire admin area upon saving.
- **Update-Safe:** Your custom title persists even after updating YOURLS.
- **Secure:** Built-in security verification (Nonces) to prevent unauthorized changes.

## Installation

1. Download the latest release or clone this repository.
2. Upload the `custom-title-editor` folder to your YOURLS `user/plugins/` directory.
3. Log in to your YOURLS admin panel and go to the **Plugins** page.
4. Locate **Custom Title Editor** and click **Activate**.
5. Click the **Configure** button (or "Custom Title 設定" page) to set your desired page title.

### 日本語でのインストール手順

1. このリポジトリからファイルをダウンロードします。
2. `custom-title-editor` フォルダごと、サーバーの `user/plugins/` ディレクトリにアップロードします。
3. YOURLSの管理画面を開き、**Plugins** ページに移動します。
4. **Custom Title Editor** を見つけ、**Activate（有効化）** をクリックします。
5. プラグインの横に表示される **Configure** ボタン、またはメニューから設定画面を開き、好きなタイトルを入力して保存してください。

## Requirements
